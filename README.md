# Jus Gentium

A phone app (an installable web app, or PWA) for keeping up with international law and geopolitics. It covers Public International Law, International Criminal Law, Human Rights, Humanitarian Law, Dispute Settlement, Law of the Sea and Geopolitics.

Every 2 hours a GitHub Action collects the newest posts from 42 vetted sources, tags each story by field, and publishes the app on GitHub Pages. Most sources come through official RSS feeds. The ICJ, ITLOS, IRMCT and ICSID have no feed, so their press-release pages are read directly (`scripts/scrapers.py`). Nothing is rewritten or generated. Every story links to the original.

## What's in the app

- **Briefing**: today's picture. It shows how many stories each field had in the last 36 hours, a *Where law meets politics* section (news and think-tank pieces that raise a legal issue), and the top stories per field. For legal fields, scholarship and institutions get priority over media.
- **Feed**: everything, grouped by day. You can filter by field, by source type (Scholarship / Institutions / Media & analysis / NGOs), or by full-text search.
- **Saved**: stories you bookmark. They stay even after they drop out of the feed.
- **Sources**: every outlet with its live status. You can mute any of them. Light and dark mode, plus "hide stories I've opened".
- Works offline with the last copy it loaded, and shows a **NEW** label on stories since your last visit.

## Layout

```
app/                 the app itself (published as-is)
  data/news.json     generated by the fetcher; not committed
scripts/feeds.json   ← the source list: add/remove outlets here
scripts/fetch_feeds.py  fetcher + topic tagger (Python stdlib only)
scripts/scrapers.py     readers for court websites without RSS (ICJ, ITLOS, IRMCT, ICSID)
scripts/make_icons.py   regenerates the app icon
.github/workflows/update.yml  refresh every 2h + deploy to GitHub Pages
```

## Run it on your computer

```bash
python3 scripts/fetch_feeds.py
python3 -m http.server 8765 --directory app   # then open http://localhost:8765
```

## Put it on your phone (one-time, ~5 minutes)

1. Create a free account at github.com if you don't have one. Then create a **new public repository**, e.g. `jus-gentium`. (GitHub Pages is free for public repos. The repo only holds code and public links.)
2. Push this folder to it:
   ```bash
   git init -b main && git add . && git commit -m "Jus Gentium"
   git remote add origin https://github.com/<you>/jus-gentium.git
   git push -u origin main
   ```
3. In the repo, go to **Settings → Pages → Build and deployment → Source** and choose **GitHub Actions**.
4. Go to **Actions → Refresh news and publish → Run workflow**. After about a minute your app is live at `https://<you>.github.io/jus-gentium/`.
5. On your phone, open that link and install it:
   - **iPhone (Safari)**: Share button → *Add to Home Screen*.
   - **Android (Chrome)**: ⋮ menu → *Install app* / *Add to Home screen*.

It now opens full-screen from your home screen like any other app, and refreshes itself every 2 hours.

> GitHub pauses scheduled workflows in repos with no activity for 60 days and emails you first. If that happens, click "Enable workflow" in the Actions tab, or push any small change.

## Adding a source

Add an entry to `scripts/feeds.json`:

```json
{"id": "myblog", "name": "My Blog", "type": "scholarly", "url": "https://example.org/feed/",
 "site": "https://example.org", "topics": ["IHL"]}
```

`type` is one of `scholarly | institution | analysis | media | ngo`. `topics` are default tags for everything from that outlet. Keyword matching adds more tags, and the rules live in `TOPIC_RULES` in `fetch_feeds.py`. Leave `topics` empty for general outlets so they're tagged by keyword only. Optional `maxAgeDays` / `maxItems` keep high-volume feeds in check. Run `python3 scripts/fetch_feeds.py` to check the feed works. Its output lists each source as ok or ERR.

## Sources not included (and why)

- Blocked to automated readers (Cloudflare bot protection) or no usable listing: ECtHR, Inter-American Court, PCA, OHCHR, Chatham House, IISD Investment Treaty News, AJIL/EJIL journal feeds, Kluwer Arbitration Blog. Their work still shows up through the blogs and news outlets that cover them.
- IntLawGrrls: its old domain (`ilg2.org`) now serves an unrelated site.
- LinkedIn: no public feed, its terms forbid automated collection, and posts aren't editorially verified.
